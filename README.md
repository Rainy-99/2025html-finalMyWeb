# 不是自我介紹的自我介紹網頁

_A Personal Introduction Website_

## 📌 Project Overview

This is a personal portfolio website created as a final project for a html &css course. The website showcases information about Rainy , a first-year student at NTUE MIE.

**Title:** "不是自我介紹的自我介紹網頁" (Not Really An Introduction Introduction Website)


## 🌐 Website Structure

The website consists of 5 main pages with a shared navigation menu:

### Pages

1. **index.html** - About Me (關於我)
   - Personal introduction and background information
   - Profile with photo

2. **interest.html** - My Interests (我的興趣)
   - Showcases recent hobbies and passions

3. **Books.html** - My Book List (我的書單)
   - Collection of favorite books and reading recommendations

4. **FAQ.html** - Frequently Asked Questions
   - Common questions and answers about the site and creator

5. **website.html** - About This Website (關於這個網頁)
   - Information about how the website was created
   - Design philosophy and inspirations (influenced by Notion's design)

## 🎨 Design Philosophy

- Clean, modern aesthetic inspired by **Notion**
- Card-based layout for visual organization
- Responsive design with sidebar navigation
- Personal typography and color choices reflecting creator's preferences

## 🔧 Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Styling and layout
- **Responsive Design** - Mobile-friendly layout

## 🚀 How to Use

1. Open `index.html` in a web browser to view the website
2. Use the navigation menu on the left to browse different sections
3. Each page has its own dedicated CSS file for styling
